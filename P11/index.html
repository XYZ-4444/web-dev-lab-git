Top Story

Students Learn CSS Grid and Build Their First Newspaper Page

By Aryan Patel

CSS Grid is a two-dimensional layout system. It lets developers control rows and columns at the same time, which makes it a perfect tool for magazine and newspaper style pages.

In this practical, a three-column layout is created with grid-template-columns. The main story spans two columns, while smaller stories fill the remaining space. When the screen becomes smaller, the grid reduces to two columns and then to a single column.

Newspaper-style text flow is added with the CSS column-count property, so a long paragraph is divided into neat columns, just like in a printed paper.

In Brief

  • Flexbox is best for one-dimensional layouts.
  • Grid is best for two-dimensional layouts.
  • fr units share the free space in a grid.
  • gap adds space between rows and columns.
