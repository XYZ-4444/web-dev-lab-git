# P12 - Portfolio Projects Grid with Advanced CSS Grid

## Aim
To design a portfolio page that shows projects in a grid layout, using advanced CSS Grid features with HTML and CSS.

## Files
- `P12.html` - page structure
- `P12.css` - page styling

## Page Structure

| Section | HTML Tag | Description |
|---|---|---|
| Header | `<header>` | Name and short introduction with a gradient background |
| Navigation | `<nav>` | Links to Projects, Skills and Contact |
| Projects | `<section>` | Grid of project cards |
| Featured card | `<article>` | Large card that spans two rows |
| Project cards | `<article>` | Smaller cards with title, description, tags and button |
| Skills | `<aside>` | Sidebar list of skills |
| Footer | `<footer>` | Contact details and copyright |

## Projects Shown
- **Logmind AI** (featured): an AI tool that helps teams find the important message inside a huge pile of logs
- **Tripzy**: a web app that helps travellers plan their trips
- **TimeTable**: a web app that helps students organize their class schedule

## CSS Concepts Used
- **CSS Grid**: `display: grid` with `grid-template-columns` for the main layout (projects and skills sidebar)
- **Grid spanning**: `grid-row: span 2` so the featured card takes two rows
- **Gap**: `gap` for spacing between cards
- **Gradients**: `linear-gradient` for the header and card images
- **Flexbox**: used in the navigation bar and the skill tags
- **Cards**: `border-radius` and `box-shadow` for the card look
- **Media query**: switches to a single column on small screens

## How to Run
1. Keep `P12.html` and `P12.css` in the same folder.
2. Open `P12.html` in any web browser.
