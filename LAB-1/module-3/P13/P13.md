# P13 - Choosing Between Flexbox and Grid

## Aim
To understand when to use Flexbox and when to use CSS Grid, and how to combine both in one web page using HTML and CSS.

## Files
- `P13.html` - page structure
- `P13.css` - page styling

## Page Structure

| Section | HTML Tag | Description |
|---|---|---|
| Header | `<header>` | Page title with a badge, built with Flexbox |
| Navigation | `<nav>` | Links to Rules, Live Demo, Comparison and Contact |
| Rule of Thumb | `<section>` | Two cards explaining when to use Flexbox and when to use Grid |
| Same Items, Two Layouts | `<section>` | The same 5 items shown with Flexbox and with Grid |
| Which One Should I Use? | `<section>` | Comparison table of Flexbox and Grid |
| Nesting | `<section>` | Grid places the cards, Flexbox aligns the content inside each card |
| Quick Guide | `<aside>` | Sidebar with short tips |
| Footer | `<footer>` | Contact details and copyright |

## Rule of Thumb
- **Flexbox**: content decides the layout. Use it for one direction, such as a navbar, toolbar, tags or buttons.
- **Grid**: layout decides the content. Use it for rows and columns together, such as page structure, galleries and dashboards.
- **Both**: real websites use both together.

## Comparison

| Question | Flexbox | Grid |
|---|---|---|
| Dimensions | One (row or column) | Two (rows and columns) |
| Starts from | Content | Layout |
| Best for | Navbar, buttons, card insides | Page layout, galleries |
| Last row alignment | Items stretch or float | Stays on the grid lines |
| Overlapping items | Not natural | Easy with grid areas |

## CSS Concepts Used
- **Flexbox**: `display: flex`, `justify-content`, `align-items`, `flex: 1 1 140px` and `flex-wrap`
- **CSS Grid**: `display: grid` with `grid-template-columns` for the page layout and the card layout
- **Auto-fill columns**: `repeat(auto-fill, minmax(140px, 1fr))` keeps items on the same column lines
- **Nesting**: Grid for the outer layout and Flexbox inside each card
- **Cards and badges**: `border-radius`, `box-shadow` and coloured labels
- **Media query**: switches to a single column on small screens

## Key Observation
With the same 5 items, Flexbox stretches the items in the last row to fill the line, so the columns do not line up. Grid keeps every item on the same column lines, even in the last row.
