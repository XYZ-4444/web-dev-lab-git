# P11 - Newspaper-Style Three-Column Layout with CSS Grid

## Aim
To design a newspaper-style web page with a three-column layout using HTML and CSS Grid.

## Files
- `P11.html` - page structure
- `P11.css` - page styling

## Page Structure

| Section | HTML Tag | Description |
|---|---|---|
| Masthead | `<header>` | Newspaper title, date and price |
| Banner | `<section>` | Purple featured story strip |
| Strap | `<h2>` | Top headline of the day |
| Main story | `<article>` | Left column with headline and text |
| Photo | `<figure>` | Middle column with image and caption |
| Side story | `<aside>` | Right column with second story |

## CSS Concepts Used
- **CSS Grid**: `display: grid` with `grid-template-columns: 1fr 1.3fr 0.8fr` for the three columns
- **Flexbox**: used in the masthead info row and the banner
- **Typography**: serif fonts (`Georgia`) for the newspaper look
- **Borders**: `border-bottom: 3px double` for the masthead line
- **Media query**: switches to a single column on screens up to 700px wide

## How to Run
1. Keep `P11.html` and `P11.css` in the same folder.
2. Open `P11.html` in any web browser.
