# P10 – Portfolio Header and Footer with Flexbox

## Aim
Build a responsive portfolio page whose **header** and **footer** are laid out using CSS Flexbox.

## Files
| File | Purpose |
|------|---------|
| `P10.html` | Page structure (header, main, footer) |
| `P10.css` | Flexbox styling and responsive rules |
| `P10.md` | Practical notes |

## Features
- **Sticky header** with logo, centered nav links and action buttons (GitHub, Hire me)
- **Hero** and **content panels** (About, Projects) inside a column-flex `main`
- **Sticky footer**: `body` is a column flex container and `main` uses `flex: 1`
- **Footer columns** with different flex values (brand column is twice as wide)
- **Bottom bar** with copyright on the left and social links on the right

## Flexbox Concepts Used
| Property | Used for |
|----------|----------|
| `display: flex` | Header, nav, footer, bottom bar |
| `flex-direction: column` | Sticky footer layout, `main` |
| `flex: 1` | Nav and `main` fill free space |
| `flex: 2 1 260px` | Wider footer brand column |
| `flex-wrap: wrap` | Items wrap on small screens |
| `justify-content` / `align-items` | Alignment of items |
| `gap` | Spacing between items |
| `margin-left: auto` | Push buttons to the far right |
| `order` | Move nav below logo on tablets |

## Responsive Behavior
- **≤ 900px:** nav moves to its own row below the logo and buttons.
- **≤ 600px:** footer bottom bar stacks vertically; the outline button is hidden.

## How to Run
Open `P10.html` in a browser (or use Live Server) and resize the window to see the layout change.

## Output
Page sections: **Header → Hero → About → Projects → Footer**

## Conclusion
Flexbox makes it easy to build flexible, responsive headers and footers, including a footer that always stays at the bottom of the screen.
