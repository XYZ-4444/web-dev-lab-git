A simple web page I made to learn Git and GitHub.

## What's inside

- `P1.html` - the main web page
- `P1.css` - the style file
- `P1.md` - this file


## What I learned

- Navigating folders in the terminal
- Creating files
- Saving changes with Git
- pwd shows where you are right now.
- ls lists what’s in the current folder (ls -la also shows hidden files like .git).
- cd foldername moves into a folder, cd .. goes up one level, cd ~ goes to your home folder, and cd - goes back to the previous folder.
- mkdir my-project creates a folder, and mkdir -p a/b/c creates nested folders in one go.
- touch README.md creates an empty file.
- cp, mv, and rm copy, move/rename, and delete files.
