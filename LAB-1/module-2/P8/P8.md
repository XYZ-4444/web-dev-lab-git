# P8: Sticky Navbar and Card Overlay Using CSS Positioning

## Aim

To understand CSS positioning by building a sticky navigation bar and project cards with a badge and a hover overlay.

## Position values used

| Value | Where I used it | What it does |
|---|---|---|
| `static` | Default for most elements | Normal page flow |
| `relative` | Project card | Keeps the card in flow and becomes the reference point for child elements |
| `absolute` | "New" badge and hover overlay | Places the element exactly inside the nearest `relative` parent |
| `sticky` | Navigation bar | Scrolls with the page, then sticks to the top of the screen |

## How it works

**1. Sticky navbar**
```css
nav {
  position: sticky;
  top: 12px;
  z-index: 10;
}
```
The navbar scrolls normally until it reaches `top: 12px`, then stays fixed there. `z-index` keeps it above the cards.

**2. Card with a badge**
```css
.card { position: relative; }

.badge {
  position: absolute;
  top: 12px;
  right: 12px;
}
```
The badge is positioned relative to its card, so it always sits in the card's top-right corner.

**3. Hover overlay**
```css
.overlay {
  position: absolute;
  inset: 0;
  opacity: 0;
  transition: opacity 0.2s;
}

.card:hover .overlay { opacity: 1; }
```
`inset: 0` makes the overlay cover the whole card. It is hidden until you hover over the card.
