# P9: Responsive Navbar and Card Grid with Flexbox

## Aim

To build a responsive navigation bar and project card grid using CSS Flexbox, and make them adapt to different screen sizes.

## Flexbox properties used

| Property | Where I used it | What it does |
|---|---|---|
| `display: flex` | Navbar, card grid, skill tags | Turns an element into a flex container |
| `justify-content: space-between` | Navbar | Logo on the left, links on the right |
| `align-items: center` | Navbar | Centers items vertically |
| `flex-wrap: wrap` | Cards and tags | Moves items to the next row when space runs out |
| `gap` | Links, cards, tags | Adds space between items |
| `flex: 1 1 280px` | Each card | Card can grow and shrink, with a minimum width of 280px |
| `flex-direction: column` | Cards and mobile menu | Stacks items vertically |
| `margin-top: auto` | Card button | Pushes the button to the bottom of the card |

## How it works

**1. Navbar**
```css
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```
The logo sits on the left and the links on the right, in one row.

**2. Card grid**
```css
.cards { display: flex; flex-wrap: wrap; gap: 20px; }
.card  { flex: 1 1 280px; }
```
Cards sit side by side on wide screens and wrap onto new rows on smaller screens.

**3. Mobile menu (no JavaScript)**
```css
@media (max-width: 768px) {
  .menu-icon { display: flex; }
  .nav-links { display: none; }
  .menu-toggle:checked ~ .nav-links { display: block; }
}
```
On small screens the links hide and a hamburger icon appears. A hidden checkbox opens and closes the menu when the icon is clicked.
