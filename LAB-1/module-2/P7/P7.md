# P7: Design Tokens and Typography System

## Aim

To build a small style guide page using CSS custom properties (design tokens) and a consistent typography system.

## What are design tokens?

Design tokens are reusable values for colors, font sizes, and spacing, stored as CSS variables. Changing one token updates the whole page.

```css
:root {
  --primary-color: #4f46e5;
  --secondary-color: #8b5cf6;
  --text-color: #222;
  --bg-color: #f1f5f9;
  --space-1: 8px;
  --space-2: 16px;
  --space-3: 24px;
}
```

Use a token with `var()`:

```css
h2 { color: var(--primary-color); }
```

## Page sections

| Section | What it shows |
|---|---|
| Color Tokens | Primary, Secondary, Accent, Background, Text |
| Typography Scale | Headings from `<h1>` to `<h6>` |
| Text Style | Strong, emphasis, highlight (`<mark>`), inline code, links, quote |
| Lists | Unordered, ordered, and definition lists |
| Spacing | 8px, 16px, and 24px spacing values, plus Primary and Outline buttons |
| Contact | Email, GitHub, and copyright in the footer |

## HTML tags used

- Headings: `<h1>` to `<h6>`
- Text: `<strong>`, `<em>`, `<mark>`, `<code>`, `<a>`, `<blockquote>`
- Code block: `<pre><code>`
- Lists: `<ul>`, `<ol>`, `<dl>`, `<dt>`, `<dd>`
- Buttons: `<button>`

## CSS concepts used

- Custom properties declared in `:root`
- `var()` to reuse values
- A typography scale with consistent heading sizes
- Spacing tokens for padding and margins
- Cards with rounded corners and soft shadows
- Gradient header and dark footer
