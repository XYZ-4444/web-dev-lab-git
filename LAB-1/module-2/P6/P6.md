# P6: Portfolio Web Page

## Aim

To build a complete personal portfolio web page with a navigation menu, profile details, project links, and CSS styling.

## Page sections

| Section | Content |
|---|---|
| Header | Name (Aryan Patel), tagline, and navigation links |
| About Me | Profile photo, caption, and short introduction |
| Education | Bosscoder School of Technology, Programming for Web Development - I |
| Skills | HTML5, CSS, Git and GitHub, Terminal basics |
| Projects | Logmind AI, Tripzy, TimeTable (each with a description and link) |
| Fun Fact | A short personal note |
| Contact | Email and GitHub link |

## HTML concepts used

- Headings and paragraphs: `<h1>`, `<h2>`, `<p>`
- Lists for navigation and skills: `<ul>`, `<li>`
- Links to sections and projects: `<a href="#about">`, `<a href="https://...">`
- Image with alt text: `<img src="photo.jpg" alt="photo of Aryan">`
- Sections of the page: `<header>`, `<section>`, `<footer>`

## CSS concepts used

- Gradient header with rounded corners
- White cards with soft shadows for each section
- Accent color for headings and links
- External stylesheet linked in the `<head>`:
  ```html
  <link rel="stylesheet" href="P6.css">
  ```
