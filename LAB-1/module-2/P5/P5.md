# P5: Semantic Bio Page

## Aim

To build a personal bio page using semantic HTML elements and style it with CSS.

## What is semantic HTML?

Semantic HTML uses tags that describe the meaning of the content, not just how it looks. This helps browsers, search engines, and screen readers understand the page.

Instead of using `<div>` for everything, I used:

| Tag | Used for |
|---|---|
| `<header>` | Name, tagline, and navigation |
| `<nav>` | Links to page sections |
| `<main>` | The main content of the page |
| `<section>` | About, Education, and Skills blocks |
| `<article>` | One self-contained item (education entry) |
| `<aside>` | Extra content such as the Fun Fact |
| `<figure>` and `<figcaption>` | Profile photo with its caption |
| `<footer>` | Contact details |

## Page sections

1. **Header:** name, "Aspiring Web Developer", and nav links
2. **About Me:** photo and short introduction
3. **Education:** Bosscoder School of Technology
4. **Skills:** HTML5, CSS, Git and GitHub, Terminal basics
5. **Fun Fact:** a short personal note
6. **Contact:** email and GitHub link

## Styling

- Indigo gradient header with centered navigation
- White cards with rounded corners and soft shadows
- Skills shown as rounded chips
- Circular profile photo with an accent border
- Dark footer for contact details
